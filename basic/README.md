# Basic Python Exercises

This folder contains beginner-friendly Python scripts for practicing core programming concepts.

## Files Overview

- `data_types.py` — examples of basic Python data types
- `number_data_type.py` — numbers, arithmetic, type conversion, and the `random` module
- `strint_data_type.py` — common string operations and formatting
- `list_data_type.py` — list methods and common list operations
- `dictionary_data_type.py` — dictionaries, keys, values, and iteration
- `tuple_data_type.py` — tuple basics, indexing, and slicing
- `function_data_type.py` — defining and calling functions
- `conditional_statements.py` — examples with `if`, `elif`, and `else`
- `conditional_problem_solving.py` — practical condition-based exercises
- `loop_problem_solving.py` — practice with loops and repeated logic
- `scope_closure.py` — examples of scope, closures, and nested functions
- `object_oriented_programming.py` — introduction to classes, objects, and methods

## Topics Covered

- Variables and data types
- Conditional statements
- Loops and repetition
- Scope and closures
- Object-oriented programming
- Strings, lists, dictionaries, and tuples
- Functions and reusable code
- Basic problem solving

## How to Run

From the repository root, run a script like this:

```bash
python basic/conditional_statements.py
```

Or, if you are already inside the basic folder:

```bash
python conditional_statements.py
```
