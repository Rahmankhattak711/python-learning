# Python Learning

A personal repository for learning Python fundamentals.

## Topics

### 1. Data Types (`data_types.py`)

Covers Python's built-in data types with commented examples:

| Type   | Example                          |
|--------|----------------------------------|
| `int`  | Whole numbers (e.g. age)         |
| `float`| Decimal numbers (e.g. miles)     |
| `str`  | Text strings (e.g. name)         |
| `dict` | Key-value pairs (e.g. studName)  |
| `list` | Ordered, mutable sequences       |
| `set`  | Unordered, unique elements       |
| `tuple`| Ordered, immutable sequences     |

Uncomment the examples in `data_types.py` and run:

```bash
python data_types.py
```
