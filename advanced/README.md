# Advanced Python Topics

This folder contains more advanced Python practice files as part of the learning journey.

## Files Overview

- `01_function.py` — basic function definitions and return values
- `02_function.py` — function examples with parameters and arguments
- `03_function.py` — more practice with function behavior and reuse
- `04_function.py` — additional function-based exercises

## Topics Covered

- Function basics
- Parameters and arguments
- Reusable code patterns
- Practice with Python functions

## How to Run

Run any script from the repository root with:

```bash
python advanced/01_function.py
```

You can replace the filename with `02_function.py`, `03_function.py`, or `04_function.py` as needed.
